# dmvs_html Documentation

dmvs_html is the HTML and CSS converter of dmvsi: a still page - its style
sheets, Tailwind CSS classes, fonts - laid out and described as a dmvsi
document, which todmvs makes a dmview view of.

See [../README.md](../README.md) for what it supports, and the dmvsi
documentation for the interface it implements.

```bash
dmf-man dmvs_html      # Main documentation
```
